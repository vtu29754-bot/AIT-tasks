# AIT Tasks - Artificial Intelligence Lab Solutions

This repository contains Python implementations of Artificial Intelligence (AI) laboratory tasks and problem-solving assignments, complete with algorithm logic and execution outputs.

## Repository Contents

| Task # | Task Title | File Name | Description / Algorithm |
| :---: | :--- | :--- | :--- |

| **Task 2** | CPU Task Scheduling | [`Task-2_CPU_Task_Scheduling_Hill_Climbing.py`](Task-2_CPU_Task_Scheduling_Hill_Climbing.py) | Hill Climbing local search optimizing CPU processor task allocation and makespan. |

## How to Run

Run any task file directly using standard Python 3:

```bash
python Task-1_Social_Network_Friend_Search_BFS.py
```
Each file includes its corresponding output commented with `# Output:` at the bottom of the script.
